# Refactor Long Files Plan

## Goal

Reduce handwritten Go files over 500 LOC by splitting oversized test suites into smaller files without changing behaviour.

## Plan

1. Baseline current Go files over 500 LOC and record the generated-code exception candidate.
2. Split long `_test.go` files by package behaviour/top-level declarations, preserving package and imports.
3. Run `gofmt` on touched Go files.
4. Recount Go files over 500 LOC and inspect any remaining offenders.
5. Run package-local tests for touched packages.
6. Run `make test` if package-local tests pass.
7. Update this plan with results and move/commit only this task's files if verification is acceptable.
